# ENG_LEARN — Освітня вебплатформа для вивчення англійської мови
<img width="1200" height="675" alt="image" src="https://github.com/user-attachments/assets/2d6dd1d2-6939-460e-a93c-cb8b1ec9d71d" />


**ENG_LEARN** — це сучасна інтерактивна вебплатформа, створена для гнучкого онлайн-навчання та автоматизованого контролю знань з англійської мови. Проєкт реалізовано на базі фреймворку **Laravel 12.x** із дотриманням архітектурного шаблону MVC.

##  Ключовий функціонал

* **Ієрархічна структура курсів:** Організація навчального матеріалу за схемою: *Розділи → Теми → Уроки*.
* **Мультимедійні заняття:** Кожен урок поєднує в собі текстову лекцію та інтегрований відеоурок (зв'язок `1:1`).
* **Модуль тестування (Квізи):** Автоматизована перевірка знань користувача після вивчення теми з миттєвим рендерингом результатів (колірне маркування помилок).
* **Особистий кабінет студента:** Перегляд профілю та повної історії спроб проходження тестів (`TestAttempt`) із фіксацією успішності.
* **Панель адміністратора (CRUD):** Повнофункціональний інтерфейс для динамічного створення, редагування та видалення розділів, тем, уроків, тестів, питань та варіантів відповідей.
* **Безпека та рольова модель:** Розмежування прав доступу (гість, авторизований студент, адміністратор) за допомогою `AdminMiddleware`, захист форм від CSRF-атак та надійне криптографічне хешування паролів (BCrypt).

##Технологічний стек

* **Backend:** PHP (>= 8.2), Laravel 12.x (Eloquent ORM, Blade, Tinker)
* **Frontend:** Bootstrap 5.3, JavaScript, Vite (збирач ресурсів)
* **Database:** MySQL (5.7 / 8.0)
* **Залежності:** Composer 2.x, Node.js (18+) & NPM

##Інструкція з локального розгортання

Для запуску проєкту у локальному середовищі розробки (наприклад, XAMPP) виконайте такі кроки:

### 1. Клонування репозиторію та перехід у директорію
```bash
git clone [https://github.com/maslovvskkaya/english-learning.git](https://github.com/your-username/english-learning.git)
cd english-learning

```

### 2. Встановлення серверних PHP-залежностей

```bash
composer install

```

### 3. Встановлення та компіляція фронтенд-ресурсів

```bash
npm install
npm run build

```

### 4. Налаштування середовища оточення

Скопіюйте файл конфігурації `.env.example` та створіть на його основі `.env`:

```bash
cp .env.example .env

```

Відкрийте файл `.env` та вкажіть актуальні реквізити підключення до вашої бази даних MySQL:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=english_learning
DB_USERNAME=root
DB_PASSWORD=

```

### 5. Генерація унікального ключа застосунку

```bash
php artisan key:generate

```

### 6. Ініціалізація бази даних (Міграції та Сидери)

Створіть структуру таблиць та наповніть систему початковим навчальним контентом:

```bash
php artisan migrate --seed

```

### 7. Запуск локального сервера

```bash
php artisan serve

```

Після цього вебплатформа буде доступна за адресою: `http://127.0.0.1:8000`.
